# Raytech Agency

The Raytech Agency homepage is a Vite and TanStack Start application focused on
web design, AI automation, and digital marketing services.

## Development

Install dependencies with Node.js and npm:

```sh
cd raytech-agency-replica-main
npm install
npm run dev
```

## Quality checks

```sh
npm run test
npm run lint
npm run build
```

See [docs/CODEBASE_AUDIT.md](docs/CODEBASE_AUDIT.md) for the architecture
audit and the planned boundaries for future CMS and CRM features.
